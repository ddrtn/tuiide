# TUI IDE — следующий этап доработок

Список составлен после сравнения TUI IDE с PyTUI IDE. Завершённый исторический
план остаётся в `TODO.md`; здесь собраны новые задачи в порядке приоритета.

## P0 — стабильность

- [x] Устранить конфликт Add watch с Ctrl+L: новая клавиша Alt+Shift+U,
  запрет зарезервированных shortcuts в редакторе и при сохранении, безопасная
  загрузка старых назначений с предупреждениями без сброса других предпочтений.
- [x] Разобрать сбой общего PTY-сценария `tuiide_integration_tests`: обновить
  устаревший маркер открытия File с учётом ANSI-оформления горячей буквы,
  сохранить реальный порядок Project/Run и добавить диагностику отсутствующего
  пункта меню. Явно перерисовывать сообщения Capture; в тесте shortcuts
  дождаться начала и отмены Capture вместо фиксированных пауз; в тесте Tools
  дождаться отрисовки выбранной темы перед применением. Общий сценарий,
  включая защиту изменённого файла, смену проекта,
  внешние изменения и recovery, проходит без ослабления проверок.
- [x] Сделать разбор всех ответов clangd устойчивым к `null`, отсутствующим
  полям и неверным JSON-типам; показывать ошибку протокола вместо молчаливого
  игнорирования и покрыть completion/hover/diagnostics regression-тестами.
- [x] Перенести явную перерисовку активной страницы `SidebarTabs` после фонового
  обновления Build, Problems, Output и Debug; добавить PTY-регрессию.
- [x] Усилить `AsyncProcess`: закрывать дескрипторы на всех error paths, хранить
  process group отдельно и удалять фоновых потомков после завершения лидера.
- [x] Усилить `PseudoTerminal`: очищать частично созданные spawn-объекты,
  ограничивать размер терминала и проверить повторный start/stop.
- [x] Проверять принадлежность закреплённого коммита Final Cut fetched upstream-
  ветке и документировать воспроизводимое обновление без локальных патчей.

## P1 — рабочие процессы

- [x] Добавить сохраняемое меню Recent Files с дедупликацией, очисткой истории
  и удалением недоступных путей.
- [x] Заменить единственную launch-настройку списком именованных Run/Debug
  configurations с созданием, клонированием, удалением и быстрым выбором.
- [x] Интегрировать CTest: discovery через JSON, запуск всех/выбранных/упавших
  тестов, test presets, панель Tests и переход из failure в исходный файл.
- [x] Добавить запуск clang-tidy, cppcheck, sanitizers и include-what-you-use для
  файла/target/проекта с выводом результатов в Analysis и Problems.
- [x] Добавить менеджер toolchain/kits: обнаружение GCC/Clang, GDB/LLDB,
  Ninja/Make, sysroot и CMake toolchain files с проверкой версий.
- [x] Расширить clangd: inlay hints, document highlights, folding ranges,
  completion resolve, selection ranges, code lens и include hierarchy.
- [x] Расширить отладку:
  - [x] Attach to Process: выбор Linux-процесса из `/proc`, отдельный режим
    GDB/MI и подтверждаемое отсоединение, оставляющее внешний процесс живым.
  - [x] Открытие core dump с выбором executable и режимом только чтения:
    стек, потоки, locals, watches, registers, evaluate, memory и disassembly.
  - [x] Сигналы inferior: просмотр политик, stop/print/pass и отправка сигнала
    с продолжением (включая подавление текущего сигнала через `signal 0`).
  - [x] Опциональный LLDB backend через DAP: выбор в Project Settings,
    launch/continue/steps, breakpoints, стек, locals, watches, registers,
    evaluate/setExpression, memory и disassembly через общий Debug UI.
